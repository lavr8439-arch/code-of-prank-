 This script is a prank designed to look like a dangerous virus or system destroyer, but it is completely harmless and performs a classic "rickroll". Upon launching, it runs a background thread to download the Rick Astley music video from the Internet and save it locally as "rickroll.mp4". At the same time, it opens a full-screen black window using Tkinter that stays on top of all other windows, displaying a "COD X TEAM" header, a retro-style dotted warning reading "PC WILL BE DESTROYED IN", and a 15-second countdown timer. Once the countdown reaches zero, the warning window closes and the script automatically plays the downloaded video in full screen using an available browser in kiosk mode or a default media player, surprising the user with the famous meme. The prank can be safely aborted at any time by pressing the Escape key.
